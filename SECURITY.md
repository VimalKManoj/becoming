# Security and privacy

The current local learning mode stores data in the browser. It is not encrypted storage and has no account boundary. Keep its exports private.

The planned cloud product derives document ownership from server-verified identity. Never accept owner IDs from clients or weaken access checks to bypass setup errors.

A public security-reporting channel has not been configured. Before public release, enable private vulnerability reporting on the chosen repository and document that channel here. Do not post credentials or other users' records in public issues.
